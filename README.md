# MORIYAマリッジパートナーズ LP

**`index.html` 1ファイルで完結します。** CSS・JavaScript・写真6点をすべて内包しているため、
GitHubにアップロードするだけで公開できます。ビルド作業も画像フォルダも不要です。

`ogp.jpg` はSNSシェア時のカード画像専用の外部ファイルです（データURIだとクローラーが読み取れないため）。
使う場合は `index.html` と同じ階層に置いてください。

| ファイル | 必須 | サイズ |
|---|---|---|
| `index.html` | ◎ | 約246KB（写真6点込み） |
| `ogp.jpg` | △ SNSシェア用 | 約97KB |

---

## 1. 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成
2. **Add file → Upload files** で `index.html` と `ogp.jpg` をドラッグ＆ドロップ
3. **Commit changes**
4. Settings → Pages → Source を `main` ブランチ / `/ (root)` に設定
5. 1〜2分後に `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます
6. 公開URLを `{{公開URL}}` に記入して再アップロード

## 2. 公開前に書き換える場所

### ① `LP_CONFIG`（ファイル下部・`<script>` の先頭）

```js
var LP_CONFIG = {
  bookingUrl: 'https://timerex.net/s/ba.08h_1a1f/83cf8db1',  // 設定済み・変更していません
  showRatingScale: true,      // 「33項目×5段階」バッジ
  showBonusReport: false,     // 診断レポートを実際に渡せるなら true
  staffIntroduction: false,   // 担当者からの個別紹介を行っているなら true（FAQに一文追加）

  staff: { lead: '', female: '' },   // 空欄なら氏名行は非表示。実在しない氏名は入れないこと

  ibj: {                       // IBJ公式データ。ここ1か所でページ全体に反映されます
    members: '110,420', omiai: '97,066', success: '19,112', offices: '4,818',
    asOf: '2026年7月', successYear: '2025年'
  },

  ibjNo1: { approved: false, badge: '…', note: '…' }  // 後述
};
```

### ② 残りの `{{ }}`（全5件・すべて `href` の中）

`{{公開URL}}` `{{運営会社URL}}` `{{プライバシーポリシーURL}}` `{{特定商取引法URL}}` `{{利用規約URL}}`

**画面に表示される未入力のプレースホルダーはありません。** 上記5件はリンク先URLのみです（リンクは効かないので公開前に必ず差し込んでください）。

## 3. セクション構成（全18ブロック）

ヘッダー → ファーストビュー → IBJ信用バー(`#ibj-stats`) → 2つの課題(`#issues`) →
婚活を前へ進める3要素(`#axis`) → IBJの出会い(`#ibj`) → MORIYAの実践型プログラム(`#method`) →
活動段階と役割分担(`#stages`) → 支援体制(`#team`) → 指導実績(`#results`) → 支援事例(`#cases`) →
WHY MORIYA(`#why`) → 料金(`#pricing`) → 向き不向き(`#fit`) → 無料婚活戦略診断(`#consult`) →
FAQ(`#faq`) → 最終CTA(`#final`) → フッター

事例カードの文章は `<script>` 内の `CASES` 配列にまとまっています。
`consent: true` のカードのみ表示、`status` は交際状況（空文字なら非表示）、`comment` は空文字なら非表示です。

## 4. CTAと計測

全CTAが `https://timerex.net/s/ba.08h_1a1f/83cf8db1` へ遷移します（UTM・クリックIDを自動で引き継ぎ、
`lp_cta=` でどのCTAから予約されたか判別できます）。

| ID | data-cta（dataLayerイベント名） | 位置 |
|---|---|---|
| `cta-header` / `cta-header-nav` | `cta_header` | ヘッダー／モバイルメニュー |
| `cta-hero` | `cta_hero` | ファーストビュー |
| `cta-ibj` | `cta_ibj` | IBJセクション |
| `cta-method` | `cta_after_method` | 支援プログラム末尾 |
| `cta-pricing` | `cta_pricing` | 料金 |
| `cta-consultation` | `cta_consult` | 無料婚活戦略診断 |
| `cta-final` | `cta_final` | 最終CTA |
| `cta-sticky` | `cta_mobile_sticky` | モバイル固定CTA |
| （なし） | `cta_footer` | フッター |

`faq_open` はFAQを開いたときに発火します（質問文をパラメータ付与）。

> 旧 `cta_after_problem` は、該当セクションが `#ibj` に置き換わったため `cta_ibj` に変更しています。
> GA4 / GTM側で旧イベント名を参照している場合は設定を更新してください。他のイベント名は変更していません。

## 5. 表示確認結果

実ブラウザ（Chromium）で 320 / 360 / **375** / **390** / 414 / **768** / 820 / 1024 / 1099 / 1100 / 1280 / **1440** / 1600px を実測。

- 横スクロール：全幅で発生なし（`scrollWidth === innerWidth`）
- H1：ページ内に1つのみ
- JavaScriptエラー：0件
- 最小文字サイズ：12.5px（本文16px以上）
- 活動段階の比較表：900px未満では段階ごとの縦カードに切り替わります（縮小した横長表にはなりません）
- 固定CTA：高さ72px、`body` に80pxの下余白を確保して本文・フッターを隠しません
- ヘッダーナビ：1100px以上で展開、それ未満はハンバーガー（ロゴ・ナビ・CTAの重なりを防ぐため）

### IBJ数値についての注意点

掲載している数値は指定どおりですが、公開情報を確認したところ次の差異がありました。**掲載前にIBJ公式の最新値をご確認ください。**

- **加盟相談所数 4,818社（2026年7月）** … IBJ公表の2026年7月KPIと一致します。
- **登録会員数 110,420名** … IBJ公表値は月末時点で110,147人、7月15日時点で110,482名とされており、いずれとも一致しません。基準日によって変動するため、参照元ページと基準日を明確にしてください。
- **1か月のお見合い成立数 97,066件** … IBJ公表の2026年7月「お見合い件数」は101,790件です。「お見合い件数」と「お見合い成立数」は定義が異なる可能性があるため、どの指標を引用しているか確認してください。
- **年間成婚者数 19,112名（2025年実績）** … IBJの連盟比較ページの注記は「成婚者数は2024年実績」となっています。対象年と、組数／名数のどちらかをご確認ください。

数値は `LP_CONFIG.ibj` の1か所を書き換えれば、ページ全体（信用バー・IBJセクション本文・注記）に反映されます。

## 7. 法務・表現上の設計

- 交際・成婚・好意を**保証する表現は使用していません**
- 他社を批判する表現、根拠のない比較表現（「他社より高め」等）は使用していません
- リクルートについては「在籍経験」表記のみ。公式プログラム・監修・認定と誤認されないよう、支援体制セクションに否認文を明記しています。ロゴは未使用です
- IBJロゴは未使用です（使用する場合はIBJから正式提供された公式素材のみ）
- IBJ公式サイトへのリンクは、主CTAより弱い小さなテキストリンクにしています
- 実在しない人物・経歴・顔写真は生成していません
